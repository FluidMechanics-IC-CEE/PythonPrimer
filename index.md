# Python Primer for Computational Fluid Dynamics

Welcome to the **Python Primer** course designed for students who are new to programming and preparing for advanced computational fluid dynamics studies.

## Course Overview

This course provides a comprehensive introduction to Python programming with a focus on numerical methods and scientific computing. It serves as a prerequisite for advanced courses in computational fluid dynamics, including the solution of advection equations, Poisson equations, and the Navier-Stokes equations.

### Target Audience

- Students with **no prior programming experience**
- Students with **no background in numerical computing**
- Future participants in computational fluid dynamics courses

### Course Objectives

By the end of this course, you will be able to:
- Write effective Python programs for scientific computing
- Use NumPy for efficient numerical operations
- Create professional visualizations with Matplotlib
- Understand fundamental numerical methods
- Apply programming skills to fluid mechanics problems
- Prepare for advanced CFD coursework

## Course Structure

The course is organized into **8 comprehensive lectures**, each building upon previous concepts:

### Fundamentals (Lectures 1-5)
1. **[Lecture 1: Python Basics](Lecture%201/)** - Variables, data types, basic operations
2. **[Lecture 2: Control Structures](Lecture%202/)** - Conditionals, loops, functions
3. **[Lecture 3: NumPy Fundamentals](Lecture%203/)** - Arrays, mathematical operations, broadcasting
4. **[Lecture 4: Matplotlib Fundamentals](Lecture%204/)** - Plotting, visualization, professional figures
5. **[Lecture 5: Mathematical Concepts](Lecture%205/)** - Numerical methods, finite differences, grid generation

### Advanced Applications (Lectures 6-8)
6. **[Lecture 6-7: Numerical Integration](Lecture%206%20and%207/)** - Integration methods, 2D applications
7. **[Lecture 8: Coding Best Practices](Lecture%208/)** - Professional code development, Taylor-Green vortex

## Learning Path

### For Complete Beginners
Start with **Lecture 1** and progress sequentially through all lectures. Each lecture includes:
- Conceptual explanations with examples
- Hands-on coding exercises
- Engineering applications
- Practice problems

### For Students with Some Programming Experience
You may skip to **Lecture 3** (NumPy) if you're comfortable with basic Python syntax, or jump directly to **Lecture 5** if you're familiar with NumPy and Matplotlib.

## Prerequisites

- **No programming experience required** for Lectures 1-5
- **Basic mathematical background** (calculus, linear algebra)
- **Python installation** (recommended: Anaconda distribution)

### Required Software

- **Python 3.7+** with packages:
  - NumPy
  - Matplotlib
  - SciPy (for advanced examples)
- **Jupyter Notebook** or any Python IDE
- **Text editor** for code development

## Exercise Philosophy

Each lecture includes practical exercises that:
- Reinforce the concepts taught
- Provide hands-on programming experience
- Connect to real engineering problems
- Build skills progressively

**Note**: Exercise solutions are available to instructors but are not publicly accessible to encourage independent problem-solving.

## Getting Started

1. **Set up your Python environment**
   - Install Anaconda Python distribution
   - Launch Jupyter Notebook
   - Test your installation with basic NumPy/Matplotlib examples

2. **Start with Lecture 1**
   - Read through the material
   - Run the code examples
   - Complete the exercises
   - Move to the next lecture when comfortable

3. **Practice regularly**
   - Programming skills develop through practice
   - Try modifying the examples
   - Experiment with different parameters
   - Create your own variations

## Connection to Fluid Mechanics

This course specifically prepares you for computational fluid dynamics by:

- **Mathematical foundations**: Numerical differentiation, integration, and grid generation
- **Programming patterns**: Working with 2D/3D arrays, field calculations, and visualization
- **Error analysis**: Understanding numerical accuracy and convergence
- **Professional practices**: Writing maintainable, documented code

The skills developed here directly apply to solving:
- **Advection equations** (fluid transport)
- **Poisson equations** (pressure, temperature fields)
- **Navier-Stokes equations** (complete fluid motion)

## Course Support

- **Self-paced learning**: Progress at your own speed
- **Comprehensive examples**: Every concept illustrated with working code
- **Engineering focus**: All examples relevant to fluid mechanics and engineering
- **Progressive difficulty**: Concepts build logically from basic to advanced
