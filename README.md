# Python Primer for Computational Fluid Dynamics

This repository contains a comprehensive introductory Python course designed for students with no prior programming experience who are preparing for advanced computational fluid dynamics coursework.

## Course Website

Visit the complete course at: **https://fluidmechanics-ic-cee.github.io/PythonPrimer/**

## Course Overview

- **8 comprehensive lectures** from basic Python to numerical methods
- **Hands-on exercises** with engineering applications  
- **Progressive difficulty** building to CFD-ready skills
- **No programming experience required** to start

## Quick Start

1. Visit the [course website](https://fluidmechanics-ic-cee.github.io/PythonPrimer/)
2. Start with [Lecture 1: Python Basics](https://fluidmechanics-ic-cee.github.io/PythonPrimer/Lecture%201/)
3. Progress through lectures sequentially
4. Complete exercises for hands-on practice
