# All Lectures

This page provides a complete overview of all lectures in the Python Primer course, with direct links to each topic.

## Course Progression

The course is designed to take you from complete beginner to being ready for advanced computational fluid dynamics. Follow the lectures in order for the best learning experience.

---

## Part I: Programming Fundamentals

### [Lecture 1: Python Basics](Lecture%201/)
**Duration**: ~3 hours | **Prerequisites**: None

Master the fundamentals of Python programming:
- Introduction to Python and scientific computing
- Variables and data types (numbers, strings, booleans)
- Basic operations and string manipulation
- Data structures (lists, tuples, dictionaries)
- Input/output operations

**Key Skills**: Variable creation, basic calculations, data organization

**Engineering Applications**: Physical quantity calculations, unit conversions, data storage

---

### [Lecture 2: Control Structures](Lecture%202/)
**Duration**: ~4 hours | **Prerequisites**: Lecture 1

Learn to control program flow and organize code:
- Conditional statements (if/elif/else)
- Loops (for, while) and loop control
- Functions and parameter passing
- Error handling basics
- Code organization principles

**Key Skills**: Decision making, repetition, code modularity

**Engineering Applications**: Flow classification, iterative calculations, data validation

---

## Part II: Scientific Computing Tools

### [Lecture 3: NumPy Fundamentals](Lecture%203/)
**Duration**: ~4 hours | **Prerequisites**: Lectures 1-2

Master numerical computing with NumPy:
- Array creation and manipulation
- Mathematical operations and functions
- Indexing, slicing, and boolean operations
- Broadcasting and vectorization
- Array reshaping and joining

**Key Skills**: Efficient numerical operations, array manipulation

**Engineering Applications**: Velocity profiles, grid generation, field calculations

---

### [Lecture 4: Matplotlib Fundamentals](Lecture%204/)
**Duration**: ~3 hours | **Prerequisites**: Lectures 1-3

Create professional scientific visualizations:
- Basic plotting (line, scatter, bar charts)
- Plot customization and styling
- Multiple subplots and layouts
- 2D plotting (contours, heatmaps, 3D surfaces)
- Saving and formatting for publications

**Key Skills**: Data visualization, professional plot creation

**Engineering Applications**: Flow visualization, temperature fields, results presentation

---

## Part III: Mathematical Methods

### [Lecture 5: Mathematical Concepts and Numerical Methods](Lecture%205/)
**Duration**: ~5 hours | **Prerequisites**: Lectures 1-4

Bridge programming and mathematics for CFD:
- Vector fields and partial derivatives
- Numerical differentiation (finite differences)
- Numerical integration methods
- Grid generation techniques
- Finite difference methods for PDEs
- Error analysis and convergence

**Key Skills**: Numerical methods, mathematical implementation

**Engineering Applications**: Heat conduction, field calculations, grid quality analysis

---

## Part IV: Advanced Applications

### [Lecture 6-7: Numerical Integration](Lecture%206%20and%207/)
**Duration**: ~6 hours | **Prerequisites**: Lectures 1-5

Apply numerical methods to engineering problems:

#### 1D Integration Methods
- Rectangle, trapezoidal, and advanced rules
- Error analysis and convergence studies
- Function integration and area calculations

#### 2D Domain Integration
- Integration over complex geometries
- Pipe flow analysis (Hagen-Poiseuille)
- Cross-sectional calculations
- Uniform and non-uniform grids

**Key Skills**: Advanced numerical integration, 2D field analysis

**Engineering Applications**: Flow rate calculations, cross-sectional analysis, heat transfer

---

### [Lecture 8: Coding Best Practices](Lecture%208/)
**Duration**: ~4 hours | **Prerequisites**: All previous lectures

Professional code development and validation:
- Code organization and documentation
- Function design and modularity
- Error handling and validation
- Performance optimization
- Taylor-Green vortex as validation case
- Numerical differentiation accuracy

**Key Skills**: Professional programming, code validation

**Engineering Applications**: Taylor-Green vortex, field verification, code quality

---
